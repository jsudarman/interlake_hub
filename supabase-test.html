Live Query Test

Runs sb.from('club_updates').select('*').limit(1) against your Supabase project. A "table not found" error still means the connection works — you just need to run the schema SQL first.

Setup Checklist

  1. Copy config.example.js → config.js in the project root.
  2. Open config.js and replace the placeholders:
      SUPABASE_URL — your Project URL (Supabase dashboard → Settings → API)
      SUPABASE_ANON_KEY — your anon public key (same page)
  3. Reload this page — all four pre-flight checks should turn green.
  4. Click Run Live Test. A "table not found" error is fine for now; it confirms the connection works.
  5. Run the schema SQL in Supabase → SQL Editor to create the club_updates and events tables.
